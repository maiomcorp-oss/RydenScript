Sobre o RydenScript

o RydenScript é uma linguagem de programação de proposito Geral focada na sintaxe Direta por meio de tags

tags qual são semelhantes ao HTML mais que é utilizado tanto pra Front-end tanto pra back-end

a linguagem não utiliza: (,[,{.

A linguagem separa parâmetros por pipes: |

O nome da linguagem carrega uma historia interessante

o nome "RydenScript" pegou a ideia de "javaScript" e "TypeScript" só que o nome Ryden foi modificado, Como o criador (Eu) gosto de hospedar sites e servidores , eu uso o Render um hospedador de servidores gratuito no plano grátis , oque o Render tem a ver com o RydenScript? ai que vem a historia, eu peguei o nome "Render" e modifiquei para "Ryden" depois juntei com "Script" resultado: RydenScript.

Arquitetura do RydenScript

o RydenScript utilizou o Winrar

um aplicativo de empacotação de de arquivos

o RydenScript usou para empacotar-se

a arquitetura do RydenScript utiliza exatos arquivos

"Editor.bat" esse arquivo é um arquivo de automação do Windows o Prompt de Comando

ele garante que o atalho do RydenScript apareça com a logo

e abra outro arquivo chamado "RydenScript.html"

o arquivo RydenScript HTML é o proprio RydenScript

o editor.bat abre ele como app via Msedge utilizando o arquivo chamado "Msedge_proxy" ele é responsavel pelo PWA que transforma o RydenScript em um app

mais antes de tudo na empacotação do Winrar ele solta esses arquivos no %localappdata% e ele inicia o arquivo "Carregar.bat"

então na arquitetura do RydenScript cada arquivo depende do outro

Uma separação importante o RydenScript.html é a estrutura que carrega o compilador e interpretador o Editor.bat não é o editor ele só deixa tudo pronto e correto.
